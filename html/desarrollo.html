Sobre el proyecto

Zona juegos es un sitio con tres minijuegos: 10000 (dados), Blackjack (cartas) y una trivia con preguntas obtenidas de una API pública. Fue desarrollado como Trabajo Práctico 1 de Informática General 2026.

Cómo lo desarrollamos

  1. Elegimos los tres juegos y definimos sus reglas.
  2. Armamos la estructura de cada página con HTML5.
  3. Diseñamos el sitio con una única hoja de estilos CSS, usando los colores de la imagen de fondo del inicio.
  4. Programamos los juegos con JavaScript.
  5. Conectamos la trivia con la API y le agregamos un temporizador de 10 segundos por pregunta.
  6. Guardamos los récords de cada juego con localStorage y los mostramos en la página de puntajes.
  7. Probamos el sitio completo y corregimos los errores que encontramos.
  8. A lo largo del proceso fuimos registrando todos los cambios con GitHub.

Tecnologías y herramientas

HTML5, CSS y JavaScript. API pública. Almacenamiento local (localStorage) con datos en formato JSON. Visual Studio Code para escribir el código, GitHub y GitHub Desktop para el repositorio, y GitHub Pages para publicar el sitio.

Uso de inteligencia artificial

Usamos un asistente de IA (Claude) para revisar el código, detectar errores y proponer mejoras de diseño. Revisamos cada propuesta y decidimos qué usar, qué modificar y qué descartar.
